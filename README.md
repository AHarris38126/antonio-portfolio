# Antonio Harris — Professional Portfolio

## Project Overview
My Module 2 final project is a three-page professional portfolio.
It presents my background in education, accounting, administration,
and leadership.

## Purpose and Audience
The website helps potential employers explore my experience,
qualifications, and career interests.

## Planning and Design
I divided the website into three pages:
- Home: Introduction and interactive career strengths.
- Résumé: Experience, education, and skills.
- Contact: A demonstration contact form.

Each page includes navigation links to the other pages.

I chose navy, teal, and white for a professional appearance.
I used consistent buttons, cards, and spacing throughout the site.
The layout adapts to smaller screens.

## Technologies
- HTML structures the pages.
- CSS styles all three pages.
- JavaScript adds interactions.
- Git and GitHub track project changes.
- GitHub Pages will host the website.

## Interactive Features
- Home: Buttons display strengths for different career areas.
- Résumé: Buttons show and hide job responsibilities.
- Contact: The form validates input and displays demo feedback.

## File Organization
- index.html
- resume.html
- contact.html
- style.css
- home.js
- resume.js
- contact.js
- README.md

## Evaluation
The Home buttons and résumé detail buttons were tested in the browser.
The contact form displayed a confirmation for valid sample information.
The contact form layout was adjusted to stack fields vertically.

## Limitations
The contact form is a frontend demonstration.
It does not send or save messages.
